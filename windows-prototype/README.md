# Windows Prototype

This directory will contain the first Windows implementation.

Planned stack:

- Tauri 2
- Rust
- React
- TypeScript
- Vite

## First Prototype Tasks

1. Scaffold Tauri + React + TypeScript.
2. Add Rust command to set a static wallpaper.
3. Add a local video wallpaper host proof of concept.
4. Add basic library folder selection.
5. Add Windows build workflow.

The prototype should not depend on SwiftUI/AppKit code from the macOS app.
